# Comparison With Other Licenses

## Business Source License

The license, by default, does not allow any production use and requires an additional-use grant to make this exception. Additionally it has a four-year [DOSP.](https://opensource.org/delayed-open-source-publication)

All fair source licenses in this repo have a two-year DOSP.

## Functional Source License.

Best License for full-fledged fair-source. It provides a two-year DOSP instead of a four-year DOSP.

The FSL provides either an Apache 2.0 or MIT relicnse, whereas we only provide Apache 2.0

Additionally, the AFSL License Key variant provides a way to lock certain features behind a license key while allowing you to open-source every change, including the "Key-walled" parts , after two years.

## Fair Core License

This license does the exact same thing the ASFL License Key variant and Plastic Fair Source License does.

The only difference is that the license terminates if any term is unenforcable.

In our licenses, only those terms which are unenforcable shall be voided. Additionally, the terms shall be reformed to the minimum extent necessary to make it enforceable.
